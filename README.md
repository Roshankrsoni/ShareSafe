# ShareSafe marketing website

Separate React + TypeScript + Tailwind CSS website. The native Swift app remains unchanged.

## Run

```sh
npm ci
npm run dev
```

Production: `npm run build` (type check, Vite build, static prerender), then `npm run preview`.
Quality checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm audit`.

## Structure

- `src/App.tsx`: semantic page components, responsive navigation, gallery and native FAQ disclosures.
- `src/styles.css`: Tailwind v4 import/theme and shared product design tokens/components.
- `src/config.ts`: central prices, launch cap, verified offer status and purchase URL.
- `src/content.ts`: gallery content and FAQs.
- `src/analytics.ts`: typed, local browser-event integration hook; no tracker or network calls.
- `scripts/prerender.tsx`: renders full React HTML for bots/no-JS reading; SEO and sitemap gating.
- `public/images/product`: optimized real screenshot assets.
- `public/product-guide.html`, `public/launch-status.html`: working supporting pages, generated by `scripts/write-guides.mjs`.
- `docs/marketing-research.md`, `docs/feature-inventory.md`, `docs/launch-readiness.md`, `docs/verification.md`: evidence and handoff.

## Pricing integration

All environments link to Dodo Payments' live hosted checkout at `https://dodo.pe/sharesafe-buy` for product `pdt_0NnhU4WmYU9pKWXnIILA7`. The header Buy button, pricing CTA, and both Download CTAs use this URL. No API credentials are stored in this static site.

The static checkout does not implement the proposed first-10/$5-afterward price change. ShareSafe's app download and licence delivery are also not configured in Dodo yet. See the launch-readiness document before treating the site as a complete sales channel.

## Deployment

`.openai/hosting.json` identifies the private Sites project and serves `dist/`. The Sites workflow helper handles source synchronization and deployment packaging. Never store its short-lived credentials here.

For another static host, deploy the contents of `dist/`. Set `site.productionUrl` only to the verified public origin. The build then generates canonical, og:url, robots and sitemap. Until then this private preview remains noindex, with an absolute sharing image on its assigned private Sites origin. Public legal/support destinations must be wired before public sale.

## Screenshots

Originals live one directory up in `../public/images/product/`. `node scripts/prepare-images.mjs` produces WebP sizes, an honest cropped review panel, and the real-app social card. It requires those local source assets; normal builds use checked-in optimized derivatives and do not require the parent app. All documents shown are fictional.

## Reference-inspired design and motion

See `docs/design-and-motion.md` for the ox.lol pattern analysis, real Three.js rendering, interactive workflow and genuine-screenshot GIF. Theme refinement is in `premium.css` and `reference.css`; motion components are independently maintained. Regenerate the downloadable GIF with `node scripts/generate-workflow-gif.mjs`. It plays only on request, with a static poster by default. WebGL is optional, loaded separately, and the page remains usable without it.
